G2M-SK: Graph Structured Generative Multiobjective ML-Assisted Stochastic Kriging

Every number, table, and figure in the manuscript is produced by this repository.

## Data statement

All data are generated by the included open source stochastic digital twin
(`twin.py`) of a 19 unit hospital with six acuity classes. **No real patient data
are used anywhere.** The twin is a synthetic simulation model with plausible
magnitudes; substitute your own validated simulator by replacing `twin.py`
(keep the `sample_scenario`, `scenario_features`, `flat_covariate`, `simulate`
interface).

## Repository layout

```
twin.py         stochastic hospital patient flow digital twin (19 units, 6 acuities)
models.py       GNN encoder, LMC deep kernel SK layer, generator/critic, baselines
train.py        offline training, prediction wrappers, conformal calibration
experiments.py  full experimental pipeline (chunked, resumable stages)
figures.py      all manuscript figures (reads out/results.json, out/arrays.npz)
eqs.py          renders the display equations used in the manuscript
out/            results.json, arrays.npz (created by experiments)
figs/           generated figures
```

## Installation

```bash
pip install torch numpy scipy matplotlib networkx pillow
```

CPU only is sufficient (the paper used 4 CPU threads). Python 3.10+.

## Reproducing the paper

The pipeline is split into short, resumable stages (each a few minutes):

```bash
# per master seed s in {0,1,2}
python3 experiments.py data0
python3 experiments.py fit0_16
python3 experiments.py fit0_32
python3 experiments.py fit0_64
python3 experiments.py abl0
python3 experiments.py extras_a     # seed 0 only: W1 + Pareto
python3 experiments.py extras_b     # seed 0 only: drift + timing/storage
python3 experiments.py data1 ; python3 experiments.py fit1_16 ; ...
```

Then:

```bash
python3 figures.py     # writes figs/*.png
python3 new_figs.py    # writes the problem-setting and twin/software figures
python3 eq2omml.py     # converts the equations to editable OMML (eqs_omml/)
node build_v3b.js      # builds the raw manuscript      (npm install docx)
python3 inject_omml.py # injects editable equations -> G2M-SK_manuscript_revised.docx
```

Results accumulate in `out/results.json`; figure arrays in `out/arrays.npz`.
All randomness is controlled by the master seeds (Latin hypercube design,
scenario sampling, torch/numpy training seeds), so reruns reproduce the
reported numbers up to floating point nondeterminism of BLAS.
